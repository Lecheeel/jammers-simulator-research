# 竞赛信息与项目边界

## 竞赛定位

本仓库围绕 2026 年全国大学生数学建模竞赛（CUMCM）B 题的官方 Windows 模拟器展开。公开工具项目将题目英文描述为 **Fast Automatic Localization and Neutralization of Radio Jammers**，中文可译为“无线电干扰源的快速自动定位与清除”。

题目场景的工程抽象是：客户端/机器人在虚拟场景中移动，通过指定频道测量干扰源，再在满足空间和频道条件时执行清除，并在虚拟时间预算内完成任务。官方模拟器负责场景、计时和成绩判定；客户端负责按照协议提交动作。

## 与本仓库的关系

本仓库不是官方模拟器，也不是竞赛官方解题包。我们做了三件事：

1. 对本地 `jammers-simulator.exe` 做 PE、Go/Wails、嵌入前端和协议层逆向记录；
2. 将已确认的场景生成、几何覆盖、生命周期和 HTTP 行为重建为 Python 兼容层；
3. 提供离线 loopback 服务和自动化回归，让客户端在不连接官方环境时可以先完成工程联调。

## 协议视图

```text
客户端 / Agent
       │ HTTP REST（本地或官方模拟器）
       ▼
进入区域 → 移动并测量 → 判断目标 → 清除 → 退出
       │
       └── 虚拟时间、频道、位置、幂等 request_id、结果记录
```

当前发布的服务实现 `/enter`、`/measure`、`/clear`、`/exit` 四个 loopback 端点。它用于测试请求格式、状态机和自动化编排；不能替代官方账号、正式测试票据、上传服务或成绩判定。

## 竞赛合规

- 竞赛期间遵守组委会章程、赛题发布规则和参赛承诺；
- 不在公开 Issue/PR 中发布未公开赛题解法、正式参数或比赛结果；
- 不把本地测试凭据、日志、抓包、数据库和真实服务地址提交到公开仓库；
- 任何需要联网的联调只使用明确授权的实验环境。
